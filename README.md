# Exercício em Portugol

Exercício de lógica de programação escrito em Portugol, feito no início do bootcamp Generation Brasil, antes da introdução ao Java.

## Como executar

Abra o arquivo `.por` no [Portugol Studio](https://univali-lite.github.io/Portugol-Studio/) ou no [Portugol Webstudio](https://portugol.dev/) e execute.
